## 公開資產保護策略

GitHub Pages 是靜態公開託管。瀏覽器要展示圖片或播放音訊，就必須能取得對應檔案；禁右鍵、隱藏 URL、JavaScript 混淆、`robots.txt` 或 HTML 提示都不能阻止有意下載者。當前頁面已加入顯著版權聲明、圖片拖曳與長按的輕度阻嚇樣式，以及搜尋引擎 `noimageindex` 提示，但這些都不是存取控制。

正式發布應完成以下不可替代的措施：

1. **原件私有化**：高解析度原圖、完整高品質歌曲與授權文件只保存在私人儲存空間；不得提交到公開倉庫。
2. **只發布衍生副本**：圖片先縮小並將 `© 2026 Deng Ziliang · Non-commercial` 永久寫入像素；音訊只匯出授權允許的時長、位元率與聲道版本。
3. **清理公開 Git 歷史**：直接刪除工作樹檔案不會移除舊 commit 中的版本。須先備份，再用 GitHub 建議的敏感資料清除流程重寫歷史並處理既有 fork / clone。此操作具破壞性，必須另行確認後執行。
4. **保留證據**：為每個公開副本登記原件、公開檔案 SHA-256、權利人、授權文件、期限、地域、允許時長、禁止用途與下架聯絡人。
5. **定期檢查**：發布後檢查倉庫 commit 歷史、Actions artifact、Pages URL 與搜尋引擎快取；發現未授權副本時依平台流程發出下架通知。

若不能確認歌曲的公開網路傳播與複製許可，安全做法是停止部署音訊，而不是只增加「非商用」聲明。

## 授權核對清單

取得《照片》相关授权后，至少确认下列许可覆盖公开网页发布：

1. 音频录音制品及词曲权利；允许把音频文件作为 GitHub Pages 静态资源提供。
2. 歌词文字使用许可；只有该项明确后，才能写入任何歌词片段。
3. 单依纯照片/肖像的公开网络展示、编辑与衍生海报使用许可；网络搜索到的照片不能自动作为可用底片。
4. 字体的网页嵌入或分发许可；当前使用系统 `Kaiti SC` / `STKaiti` 等回退字体，不上传字体文件。

替換音訊時，應以不含個人資料的內部登記保存：授權編號、授權方、期限、地域、允許公開的時長與品質、禁止用途、原件及公開副本 SHA-256、下架聯絡人。公開倉庫只保存已批准的衍生副本，不保存授權合同或完整原件。
