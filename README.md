# 蛋島留念 · NFC 數字小刊

一份為南京 2026 年 8 月 22–23 日留念而製作的單依純主題數字小刊。使用者以支援 NDEF 的 NFC 標籤開啟 GitHub Pages，在手機瀏覽器中閱讀紙刊式海報、翻看照片背面文字並自主播放音樂。

## 線上入口

- GitHub Pages：<https://edeva.github.io/NFC-offline-project/>
- GitHub 倉庫：<https://github.com/EDEVA/NFC-offline-project>

Pages 是公開的靜態網站。第一次開啟及瀏覽器快取失效後需要網路連線；NFC 標籤只保存網站 URL，不保存網頁、圖片或音樂檔案。

## 使用方法

### 訪客

1. 用手機輕觸已寫入本專案 Pages URL 的 NFC 標籤，或直接開啟上方連結。
2. 點按 `PLAY` 開始或暫停音樂，使用 `PREV` / `NEXT` 切換曲目。
3. 點按任一海報進入預覽，再點按照片翻到背面。

手機瀏覽器通常禁止未經使用者操作自動播放音訊，因此首次播放需主動點按。

### 本地預覽

```bash
python3 -m http.server 8000 --directory web
```

然後開啟 <http://localhost:8000/>。請使用 HTTP 預覽，不要直接以 `file://` 開啟，以免瀏覽器的媒體與模組安全策略造成行為差異。

### 寫入 NFC 標籤

用 NFC 寫卡工具新增一筆 NDEF URL 記錄，內容為正式 Pages HTTPS 地址。先在目標 iOS / Android 手機上反覆驗證，再決定是否把標籤鎖為唯讀；鎖定通常不可逆。
